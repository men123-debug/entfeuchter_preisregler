# Entfeuchter Preisregler

Home-Assistant-Integration für eine Hysterese-Regelung mit preisabhängigem
Sollwert und Erkennung natürlicher Trocknung.

## Installation über HACS

1. HACS -> Benutzerdefinierte Repositories -> dieses Repo als "Integration" hinzufügen
2. "Entfeuchter Preisregler" installieren, Home Assistant neu starten
3. Integration hinzufügen -> Luftfeuchtigkeits-Sensor, Schalter, Strompreis-Sensor auswählen
